# חומרי הסבר וצילומי מסך להגשת BECS

## פתיחת החומרים

- `guide.he.html` — מדריך בעברית עם שמונת הצילומים בתוכו. אפשר לפתוח ישירות בדפדפן, גם בלי שהפרויקט פועל. לחיצה על צילום מגדילה אותו. כפתור ההדפסה מאפשר להדפיס או לשמור כ־PDF באמצעות הדפדפן.
- `explanations.he.md` — אותו תוכן בפורמט טקסט לעריכה ולצפייה ב-GitHub, עם קישורים לצילומים.
- `screenshots/` — שמונה קובצי PNG מקוריים של היישום הפועל.
- `../BECS-submission.zip` — חבילה מרוכזת הכוללת את כל החומרים שבתיקייה זו. יש לחלץ לפני פתיחת הקבצים.
- `build_guide.py` — סקריפט Python לבנייה מחדש של המדריך והארכיון לאחר עריכת ההסברים. אינו משנה נתונים ביישום.

## מה כבר הוכן

- [x] צילום טופס תרומה עם ארבעת השדות הנדרשים.
- [x] צילום אישור התרומה והשינוי במלאי.
- [x] צילום המלצה על שילוב סוגים מתאימים ואישור ניפוק בשגרה.
- [x] צילום הודעת מחסור ללא ניפוק.
- [x] צילום אישור ניפוק בחירום.
- [x] צילום ניפוק כל מלאי O- והודעת מלאי ריק.
- [x] צילום חלופה זמינה כאשר הסוג המבוקש אזל.
- [x] הסבר בעברית על כל תרחיש, האלגוריתם, מסד הנתונים והבדיקות.

## נותר לפני ההגשה לקורס

- [ ] לבדוק את כל חומרי ההגשה מול קובץ שקפי הקורס המעודכן, שטרם סופק.
- [ ] להשלים את פרטי המגישים ומספרי הסטודנט לפי דרישות הקורס.
- [ ] לוודא את פורמט ההגשה הנדרש באתר הקורס ולצרף את קוד הפרויקט בהתאם.

המדריך מתייחס למטלת BECS שנמסרה. הוא אינו מהווה אישור לעמידה בדרישות נוספות שעשויות להופיע בשקפי הקורס. קובץ ה-ZIP מכיל חומרי תיעוד בלבד; קוד הפרויקט נמצא במאגר הראשי.

## פרטי הצילום

הצילומים נלקחו ב-16.09.2026 מתוך היישום המקומי עם נתונים מלאכותיים בלבד, במסד נפרד בשם `bloodbank_submission`. תהליך ההדגמה מסתיים ב-27 מנות זמינות. מסד העבודה הרגיל אינו מושפע. לא שונו ערכים בתמונות; כל צילום מציג מצב שהתקבל מפעולה ביישום.

לבנייה מחדש, משורש המאגר:

```sh
python docs/submission/build_guide.py
```
